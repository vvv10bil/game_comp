# Статичні асети клієнта

Файли з цієї папки Vite роздає за абсолютним шляхом без обробки.
Наприклад, `client/public/intro720p.webm` буде доступний як `/intro720p.webm`.

## Опціонально: фонове відео в hero-банері

Додаток підтримує відео-фон на дашборді (CS2 intro). Файл не комітиться
в репозиторій (через розмір і авторські права Valve) — треба покласти
вручну.

### Як додати

1. Знайди файл у локально встановленій грі:
   ```
   <Steam>/steamapps/common/Counter-Strike Global Offensive/game/csgo/panorama/videos/intro720p.webm
   ```
2. Скопіюй його сюди: `client/public/intro720p.webm`
3. Перезавантаж сторінку — відео автоматично з'явиться як фон hero-банера.

### Якщо файлу немає

Це нормально. Компонент `<video>` має `onError`, який видаляє себе при
404 — лишається градієнтний фон без видимих помилок.

### Завантаження файлу в Codespaces

У VS Code (включно з вебверсією Codespaces) можна просто **перетягнути**
файл з провідника на папку `client/public/` у дереві Explorer.
